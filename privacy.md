## Who runs this

One person. The same person who built the ghee rig, publishing here as JD. There is no company behind it, no team, and nothing underneath it that sells or brokers data. The contact address at the foot of this page reaches that person directly.

## What the website collects

The pages themselves collect nothing. There is no account to create, this site sets no cookies of its own, and no analytics script runs on any page here. There is one form, and it is described in its own section below.

Two things do happen that are worth naming. The site is hosted on GitHub Pages, so GitHub records ordinary server log information when a page is served, including IP addresses. That collection is GitHub's, not mine, and it is described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

The story pages embed a YouTube player. Once a video loads, YouTube sets its own cookies and collects its own data about that playback, under the [Google Privacy Policy](https://policies.google.com/privacy).

## The review form

There is one form on this site, reached from the [review page](review.html), for telling me how a jar of the ghee turned out. Filling it in is optional and nothing here depends on it.

It is a Google Form, so it runs on Google's servers rather than mine and Google handles the submission itself under the [Google Privacy Policy](https://policies.google.com/privacy). The answers arrive in a spreadsheet in my own Google Drive, which nobody else can open.

This is everything it asks for.

| Four ratings | How the jar was overall, and its smell, its colour and its texture, each out of five |
| A box to write in | Optional, and most people will leave it empty |
| Yes or no | Whether I may quote what you wrote on this site. Skipping the question counts as no |
| Your name | Optional, and it is only there for anyone who wants their name shown beside a quote. Blank is the normal answer |
| A batch code | Optional. Which jar it was. It identifies a batch of ghee rather than a person |

Only the first question has to be answered. Everything else, the batch code included, can be left alone.

It asks for your name in one place and one place only, which is for people who want their name shown beside a quote. Leave it blank and nothing identifies you. It does not ask for your email address, it does not ask you to sign in to anything, and it collects nothing else about you at all. If you type your own name into the box to write in, it is in there because you chose to put it there, and the same goes for any other detail about yourself.

Nothing you write appears on this site unless you tick the box that says it may.

## The program that uses YouTube

Separate from the website, a small program runs on my own computer and publishes videos to my own YouTube channel. Signing it in with Google asks for permission to upload videos and manage the details of videos on that channel. Here is exactly what that covers.

| What it reads | The list of videos on my own channel, and their titles, descriptions, tags, thumbnails and privacy settings |
| What it writes | New video uploads, and edits to those same fields on videos already on that channel |
| What it does not use | Comments, subscriber information, messages, payment or profile details, or any channel other than my own |

Only my own Google account ever signs in to it. The program is not distributed, there is no way for another person to connect their account to it, and no data belonging to anyone else passes through it at any point.

## Where the sign-in tokens live

Signing in produces an access token and a refresh token. Both are written to a file on my own computer and nowhere else. They are never uploaded to a server, never included in a backup service, and never shared.

That access can be withdrawn at any time from the [Google account permissions page](https://myaccount.google.com/permissions), which invalidates the token straight away. Deleting the local file does the same for the copy I hold.

## Limited use

Information received from Google APIs is handled in line with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements. In practice that data is used for one thing only, publishing and maintaining videos on my own channel. It is not transferred to anyone, not used for advertising or any model training, not sold, and no person other than me sees it.

## YouTube

The program uses YouTube API Services. Anyone using it is agreeing to the [YouTube Terms of Service](https://www.youtube.com/t/terms), and the way Google handles data under that agreement is set out in the [Google Privacy Policy](https://policies.google.com/privacy).

## Keeping things and deleting them

Video files and the sensor logs from the ghee runs sit on my own machines. Sign-in tokens are kept only while the publishing program is actually in use and are deleted once it is not.

Reviews sent through the form are kept, and kept for a long time, because the entire point of them is to compare one batch against the next over months. They sit in a spreadsheet only I can open and each one carries a batch code rather than a person. Nothing else is retained about a visitor to this site, because nothing else is gathered.

You can ask for a copy of anything held about you, or ask for it to be deleted. Write to the address below. If you have sent a review and want it removed, tell me roughly when you sent it and what it said, because there is no name attached for me to search for. Every request gets a reply.

## When this changes

If what the program does changes, this page changes with it, and the date in the line under the title moves. There is no mailing list to announce it, so the page itself is the record.
