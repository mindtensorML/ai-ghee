# Component photographs

Sources for the three board photographs in the circuit diagram. Originals are
in `src/`. The versions beside this file are the treated ones the drawing
uses, trimmed with the white ground swapped for the page colour so each board
sits on its card rather than as a white rectangle on top of it, then
desaturated and warmed to the palette.

`make_schematic.py` embeds them into the SVG as base64. An SVG loaded in an
img tag is not allowed to fetch anything, so a linked file would not appear.
