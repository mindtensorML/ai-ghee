Privacy

What this site and the program behind it do with data. It stays short because very little happens. Last updated 16 September 2026.

01

Who runs this

One person. The same person who built the ghee rig, publishing here as JD. There is no company behind it, no team, and nothing underneath it that sells or brokers data. The contact address at the foot of this page reaches that person directly.

02

What the website collects

Nothing, directly. There is no account to create, no form to submit, and this site sets no cookies of its own. No analytics script runs on any page here.

Two things do happen that are worth naming. The site is hosted on GitHub Pages, so GitHub records ordinary server log information when a page is served, including IP addresses. That collection is GitHub's, not mine, and it is described in the GitHub Privacy Statement.

The story pages embed a YouTube player. Once a video loads, YouTube sets its own cookies and collects its own data about that playback, under the Google Privacy Policy.

03

The program that uses YouTube

Separate from the website, a small program runs on my own computer and publishes videos to my own YouTube channel. Signing it in with Google asks for permission to upload videos and manage the details of videos on that channel. Here is exactly what that covers.

  • What it readsThe list of videos on my own channel, and their titles, descriptions, tags, thumbnails and privacy settings
  • What it writesNew video uploads, and edits to those same fields on videos already on that channel
  • What it does not useComments, subscriber information, messages, payment or profile details, or any channel other than my own

Only my own Google account ever signs in to it. The program is not distributed, there is no way for another person to connect their account to it, and no data belonging to anyone else passes through it at any point.

04

Where the sign-in tokens live

Signing in produces an access token and a refresh token. Both are written to a file on my own computer and nowhere else. They are never uploaded to a server, never included in a backup service, and never shared.

That access can be withdrawn at any time from the Google account permissions page, which invalidates the token straight away. Deleting the local file does the same for the copy I hold.

05

Limited use

Information received from Google APIs is handled in line with the Google API Services User Data Policy, including its Limited Use requirements. In practice that data is used for one thing only, publishing and maintaining videos on my own channel. It is not transferred to anyone, not used for advertising or any model training, not sold, and no person other than me sees it.

06

YouTube

The program uses YouTube API Services. Anyone using it is agreeing to the YouTube Terms of Service, and the way Google handles data under that agreement is set out in the Google Privacy Policy.

07

Keeping things and deleting them

Video files and the sensor logs from the ghee runs sit on my own machines. Sign-in tokens are kept only while the publishing program is actually in use and are deleted once it is not. Nothing at all is retained about a visitor to this site, because nothing is gathered in the first place.

You can still ask for a copy of anything held about you, or ask for it to be deleted. Write to the address below. The likely answer is that there is nothing to send, but every request gets a reply.

08

When this changes

If what the program does changes, this page changes with it, and the date in the line under the title moves. There is no mailing list to announce it, so the page itself is the record.

Questions about any of this, or a request to see or delete something. aighee@proton.me
